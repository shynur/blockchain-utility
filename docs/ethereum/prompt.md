在 @whitepaper-zh-annotated.md (一份中英文对照翻译的 Ethereum 白皮书) 中添加批注.

批注类型包括:
- 需要特别关注的地方
- 章节开始处, 作为导语
- 章节结尾, 作为总结
- 名词解释
- 所叙述的某些事情的背景信息或历史
- 难以理解的地方
- 洞见性的评语
- 举例说明某些概念或过程
- 与 Bitcoin 的不同之处
- 分析某些特性的取舍与优劣
- 对文章中某些一概而过的地方进行补充说明
- 历史与当前的差异
- 现实实现
- etc.  你认为需要批注的地方

批注的格式:
- 首先声明被批注的是什么, 然后用 `<br />` 换行, 再写下批注
- 使用 markdown 的引用语法, i.e. `> `

批注的位置:
- 批注总是刚好跟在被批注的语句所在的那一段的中文翻译的后面
- 一个段落后面可以有很多个批注, 每个批注作为一个单独的引用段落出现
- 批注不要打断列表或任何多行结构, 这类多行结构中有多处需要批注的地方时, 留到整个结构的最后批注

批注的风格:
- 保证正确性
- 通俗易懂
- 语言简洁
