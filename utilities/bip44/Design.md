# 网页版 BIP 44 钱包

## UI & UX

### word/passphrase 输入框

App 根据输入的单词数量, 自动判断使用了哪种词数的方案.
有了助记词和 passphrase, app 内部可以生成 master private key 了.

每次完成一个单词, 立即校验词数是否为 12/15/18/21/24 之一;
若命中, 则立即执行校验及后续计算; 若继续输入, 前次结果作废, 并重新校验并生成 master private key.

#### 助记词 (仅支持英文)

##### 合法字符

- 英文字母
- 空白字符

##### 输入过滤

- 忽略所有 非法字符 的 击键/文本粘贴.

- 输入的文本必须以英文字母开头, 否则
  - 忽略相应的击键
  - 如果是粘贴的文本, 则一直 trim 到首个非空白字符

##### 隐私保护

正在输入单词中, 单词完整显示.
删除仅删除一个字符.

当输入空白字符时, 表示刚才那个单词已输入完毕, 显示成 `①②③④⑤⑥⑦⑧⑨⑩⑪⑫⑬⑭⑮⑯⑰⑱⑲⑳㉑㉒㉓㉔` 中的一个, 表示第 N 个 word.
同时, 开始输入下一个单词.
单词之间多余的空白字符会被忽略, 仅保留一个空格.

当下一个单词还没字母时, 所有单词都是 `①②③④⑤⑥⑦⑧⑨⑩⑪⑫⑬⑭⑮⑯⑰⑱⑲⑳㉑㉒㉓㉔` 中的某一个, 此时删除一次, 会删除前面的整个单词.

(用户可以在输入全部的助记词之后, 故意追加一个空格, 使得最后一个 word 也隐藏起来.)

#### passphrase

位于 word 输入框之后.

##### 合法字符

- 非空白字符
- 普通空格 (` `)

##### 输入过滤

- 忽略所有 非法字符 的 击键/文本粘贴.

##### 隐私保护

每个字符都会显示成 `*`.

### xpub/xprv 输入框

入口除了 word/passphrase 输入框, 还有 xpub/xprv 输入框.

word 输入框检测到粘贴或击键的第一个非空白字符是 x 后,
则对后面的字符继续检测, 如果是完整的 `xpub` 或 `xprv`,
则 word 输入框会将输入当成 xpub/xprv 处理, 此时切换过滤规则, 只允许 base58 字符被写入;
同时 passphrase 输入框被隐藏, 但已输入的 passphrase 会保留.
若用户删除字符导致前缀不再是完整的 `xpub` 或 `xprv`, 则回退到助记词模式.

输入 xpub 或 xprv 时, 在第 `111` (0-indexed) 个字符处显示 `|` 表示合法的文本长度,
供用户核对.

到达 111 字符时自动触发校验.

#### xprv

输入 xprv 时, 除了 `xprv` 这个前缀, 后续字符全部显示成 `*`.

### Path 选择

对于导入的 xprv/xpub, 它的 path 是定死的, 只能选择后续的 子 path.
但 app 可以通过 xprv/xpub 获取它的 `depth` 和 `i`,
对于 depth >= 1, 已走过的 path 的最后一个节点是可以据此显示的,
其余只能显示 `?`, 但用户可以手动指定 (仅供用户自己参考).

#### `purpose'`

无法选择, 固定 `44': BIP 44`.

#### `coin_type'`

默认 BTC, 允许选择其它一些常见的币种.

格式 `数字': 币种`.

#### `account'`

是一个输入框, 后面有个 `H`.

输入框长度为 1, 会根据输入动态变长.

#### `change`

是一个 switch, 备注会根据 switch 状态切换.

switch 上显示当前值 (`0` 或 `1`), 备注使用中文说明.

#### `address_index`

输入框, 按回车确认输入.
可以输入多个.

合法范围: `[0, 2^31)`, 输入时自动检测范围.
列表自动去重, 按从小到大排序.

每个输入会加入到已输入列表, 每个元素后面有个 `x` 可以移除该元素.

### 生成 xprv/xpub/k/K/A

每个 path 选项后面, 都可以选择是否要在此节点处生成 xprv/xpub.

只有 `address_index` 允许额外选择是否生成 `k` 和 `K`.
当 `coin_type'` 是 BTC 或 BTC testnet 时, `address_index` 额外允许选择是否生成 `A`.
当前 `A` 只覆盖 Bitcoin mainnet/testnet P2PKH 地址.

可多选.

#### k

k 表示私钥, 以 hex 格式展示.

#### K

K 表示压缩公钥 (33 bytes), 以 hex 格式展示.

#### A

A 表示 Bitcoin P2PKH address.

#### xprv

若无法生成 xprv (例如 使用了 xpub 进行导入), 则压根不显示该选项.

默认使用 `xprv***` (此处省略若干个 `*`) 格式隐藏, 后有一个图标用来切换是否要隐藏.

## 报错

出错时, 需要在诱因处用红字显示报错信息以及预期输入或可能的解决方案 (若有).

## 响应式

适配 PC 端与移动端.
