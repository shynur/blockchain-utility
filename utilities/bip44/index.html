Offline BIP 44 wallet

助记词钱包

输入英文 BIP 39 助记词和 passphrase, 或直接导入 xpub/xprv, 生成 BIP 44 路径上的 xpub / xprv / 压缩公钥。

隐私提示 请在可信浏览器环境中离线使用。xprv 默认隐藏, passphrase 不会明文显示。

入口

助记词仅支持英文; 如果输入以完整 xpub/xprv 开头, 会自动切换到导入模式。

mnemonic

Path 选择

m / 44' / 0' / 0' / 0 / {address_index}

purpose' 44'
change

0: external / receiving addresses

root 导入 / master 节点

状态

等待输入。

生成结果

xprv 默认隐藏, 点击每条结果里的显示按钮可临时查看。
